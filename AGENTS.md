# Publicación de LuzStudio Ideas

- Este repositorio público distribuye instaladores; no subir código privado, apuntes, credenciales o llaves de firma.
- Publicar cada versión como un GitHub Release separado con tag `vX.Y.Z`, APK firmado adjunto, novedades y SHA-256.
- Comprobar versión, código Android y firma antes de publicar. Las actualizaciones deben conservar la firma original.
- Usar un borrador para preparar los adjuntos; publicar después de verificar sus hashes. Marcar como Latest sólo la estable más reciente.
- Conservar releases, tags y archivos anteriores; no reemplazar APK publicados ni forzar push. Los releases históricos usan el binario original, sin recompilar ni inventar fechas.
- Actualizar el README con la versión actual y el historial. Mantener los enlaces antiguos de `android/`.
- La autora autoriza commit y push de los cambios verificados y la publicación de releases; sincronizar primero y comprobar al terminar que local y remoto coinciden.
