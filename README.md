# LuzStudio Ideas — Descargas

Repositorio público destinado únicamente a los instaladores oficiales de **LuzStudio Ideas para Android**. El código fuente permanece privado y las ideas nunca se suben a este repositorio.

## Versión actual

- [Descargar LuzStudio Ideas 1.0.4 para Android](https://github.com/yessvs-bit/LuzStudio-Ideas-downloads/releases/download/v1.0.4/LuzStudio-Ideas-1.0.4.apk)
- SHA-256: `C537915494A4B9C1E68F677FB1C9AF0B26910D8EA0D2EC0DD74EC826E0D45190`

Es un APK firmado que incluye la app y sus datos se mantienen sólo en el dispositivo. En Android, si es la primera vez que instalás una APK descargada, habilitá temporalmente **Instalar apps desconocidas** para el navegador o gestor de archivos que usaste.

## Novedades de 1.0.4

- Recuperación de respaldos `.json` y `.lseideas` desde Configuración, sin borrar las ideas actuales.
- Validación completa antes de importar, combinación por UUID y conservación de la revisión más reciente.
- Prueba opcional de escritura automática en una carpeta elegida mediante el selector de Android. Depende de que el proveedor de archivos del teléfono permita escribir en la carpeta; el guardado local y la exportación manual permanecen disponibles.

Instalar como actualización de la versión anterior, sin desinstalar, para conservar los apuntes locales.
