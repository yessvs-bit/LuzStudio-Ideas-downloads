# LuzStudio Ideas — Descargas

Repositorio público destinado únicamente a los instaladores oficiales de **LuzStudio Ideas para Android**. El código fuente permanece privado y las ideas nunca se suben a este repositorio.

## Versión actual

- [Descargar LuzStudio Ideas 1.0.5 para Android](https://github.com/yessvs-bit/LuzStudio-Ideas-downloads/releases/download/v1.0.5/LuzStudio-Ideas-1.0.5.apk)
- SHA-256: `E89317BEDD0859D6808C7C0EED70EA917C9D54E0E300CF321E46BD8F37A6F95B`

Es un APK firmado que incluye la app y sus datos se mantienen sólo en el dispositivo. En Android, si es la primera vez que instalás una APK descargada, habilitá temporalmente **Instalar apps desconocidas** para el navegador o gestor de archivos que usaste.

## Novedades de 1.0.5

- Una idea pasa automáticamente de **Pendientes** a **Sincronizadas** sólo después de escribirse correctamente en la carpeta elegida.
- Editar una idea sincronizada vuelve a dejar su nueva revisión pendiente hasta completar otra escritura.
- **Respaldo** incluye todas las ideas y nunca modifica su estado de sincronización.
- Conserva la recuperación segura de archivos `.json` y `.lseideas` incorporada en 1.0.4.

Instalar como actualización de la versión anterior, sin desinstalar, para conservar los apuntes locales.
