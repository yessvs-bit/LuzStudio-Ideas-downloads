# LuzStudio Ideas — Descargas

Repositorio público destinado únicamente a los instaladores oficiales de **LuzStudio Ideas para Android**. El código fuente permanece privado y las ideas nunca se suben a este repositorio.

## Versión actual

- [Descargar LuzStudio Ideas 1.0.3 para Android](https://github.com/yessvs-bit/LuzStudio-Ideas-downloads/releases/download/v1.0.3/LuzStudio-Ideas-1.0.3.apk)
- SHA-256: `D9315F6E7E30571F52573AB599BD227F8AF6E5E9879A6B28625E5079D51EDF36`

Es un APK firmado que incluye la app y sus datos se mantienen sólo en el dispositivo. En Android, si es la primera vez que instalás una APK descargada, habilitá temporalmente **Instalar apps desconocidas** para el navegador o gestor de archivos que usaste.

## Novedades de 1.0.3

- Bandejas separadas para ideas pendientes y exportadas: las exportadas ya no se mezclan con las que faltan llevar a LSE.
- Abrir una idea exportada no la vuelve pendiente; sólo una edición real la devuelve a la bandeja de pendientes.
- Verificación manual y automática de actualizaciones desde Configuración, sin enviar apuntes ni datos personales.

Instalar como actualización de la versión anterior, sin desinstalar, para conservar los apuntes locales.
